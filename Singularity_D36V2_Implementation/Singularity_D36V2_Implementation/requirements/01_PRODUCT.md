# Product and UI
Singularity — Pension & Public Grievances, Assam government context. Desktop web only, light only. Internal officer workspace; no citizen public registration or marketing page. Branding Search. Context. Act. Remove BrahmaGPT/Trimurti and corporate Alpha–Epsilon data from active government UI. Preserve existing data in separate namespace or backup; do not destructively migrate unrelated environments.

Persistent sidebar exactly Search, Apps, People. Logo and collapse at top; profile at bottom, notifications/help/context in header. Width 224/64 px. Desktop 1024–1920, target 1440×900. Search opens conversational agent; history drawer/new chat inside Search. Profile contains preferences, language, responsibilities, security, admin and logout. No dark mode. Use white #FFFFFF, sidebar #F6F7F9, secondary #F8FAFC, ink #17212B, muted #667085, border #E2E7ED, accent #2457A6, selected #EAF1FC. Inter/Geist, 14px body, 24–28px titles, 8px spacing, 6–10px radius, restrained outlines, accessible focus and contrast. Avoid gradients, generic AI imagery, giant cards, technical provider labels. English primary; Assamese/Hindi core labels if translations verified; unsupported voice/transcription clearly unavailable.

## Search
Default heading How can I assist you today? Composer: Ask a question, find a record or assign work… Attachment, sources, submit, stop, voice if supported. Suggestions pension investigation, grievances, rules, office note, analytics, daily work. Recent conversations/drafts/tasks. In conversation keep composer at bottom, inline factual citations, sources drawer with exact page/anchor/version, related cases/officers, tool progress, tables/charts, actual document/task/approval links, revision and follow-up. Do not force user to select mode. Document split view conversation/editor with version history, download/share/review. Generated DOCX, XLSX, PDF, PPTX files must be valid native formats. Provide honest unsupported states for any unavailable operation.

## Apps
Catalogue: search, All/Connected/Available/Requests, favourites, recent, add/manage. Native Pensions, Grievances, Files, Knowledge, Approvals, Work, Analytics, Audit, Meetings, Reports. People is not duplicated. Government catalogue Kritagyata, eOffice, CPGRAMS, NIC Email, Directorate of Pension, Accountant General (A&E), Treasury, Service Book, Employee Records. Legacy register/leave/archive/department DB uses same cards and connection lifecycle. Connection states unavailable/requested/approved/configured/tested/connected/syncing/failed/restricted; only actual tested connection can show connected. Use local training adapter with clear source classification; no live credentials required. Request → system-owner approval → configure → test → grant scoped access → sync. Support design for REST/SOAP/DB/SFTP/gateway; implement only actual supported connector protocols and mark others unavailable.

Pensions: searchable registry, district/office/category/stage/age/objection/owner filters; detail tabs Overview, Service, Documents, Objections, Grievances, Timeline, Work, Approvals, Audit. Stages initiation, verification, HOO scrutiny, forwarding, authorisation, PPO, payment verification. No inferred payment. Ask Singularity scoped to case.
Grievances: register, assign, link, investigate, draft ATR/reply, review/disposal/reopening request, outcome evidence; administrative closure distinct from resolution. Files: private library, version compare, preview, download, access request, classification. Knowledge: verified rules, circulars, SOP, proposed changes, effective dates, supersession, conflict and approval. Work: tasks/owners/priorities/deadlines/dependencies/status/evidence; scheduled/reminders if implemented. Approvals: assigned/submitted/pending/returned/rejected/approved, exact version, reason, history. Analytics: query-driven counts with drilldown, export. Audit: restricted event filters, immutable event history. Meetings: agenda, minutes, action assignments; transcription only if implemented. Reports: saved generated files and filters.

## People
Directory, Organisation, Offices, Responsibilities, Workload, Relationships, Access. Real office/designation names; fictional staff identities. Clickable reporting tree with expand/collapse, zoom/pan, search and profile. Separate coordination graph for Education, Directorate of Pension, AG, Treasury; do not show them as direct reports. Profile: designation, office, manager, direct reports, work/cases, permissions, delegation; no invented real contact details. Role-aware task assignment and access requests. Avoid employee surveillance or arbitrary productivity scores. Org changes need authority and cycle checks.
